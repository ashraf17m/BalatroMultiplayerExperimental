# Balatro Multiplayer Experimental

![ModIcon](https://github.com/Balatro-Multiplayer/BalatroMultiplayer/blob/2cd9015963c1118e0b849f11e7c335f97b74f36c/assets/2x/modicon.png)

A multiplayer mod for Balatro, allowing players to compete or play together through online lobbies.

## 📥 Installation

General installation instructions for Balatro Multiplayer are available on the original project website:
[https://balatromp.com/docs/getting-started/installation](https://balatromp.com/docs/getting-started/installation)

Requires [Steamodded](https://github.com/Steamodded/smods), [Lovely Injector](https://github.com/ethangreen-dev/lovely-injector), and a compatible version of Balatro.

Quick installation steps:

1. Download the Multiplayer Experimental build you want to use
2. Extract the files into a new folder in your Balatro mods directory
3. Run the game with the required mod loader setup enabled

## 🎲 Usage

1. Launch Balatro with the multiplayer mod enabled
2. From the main menu, select "Play", then "Create Lobby"
3. Select a ruleset/gamemode
4. Press "View Code" and send the code to the players you want to play with
5. Other players select "Play", then "Join Lobby" and enter the code
6. Press "Start" to start the game

This mod requires a compatible multiplayer server. Configure the mod to use the server endpoint for the session you are joining or hosting.
   
## 🤝 Contributing

We welcome contributions to the Balatro Multiplayer Mod! Here's how you can help:

### How to Contribute

1. Fork the repository
2. Create a feature branch (`git checkout -b feature/amazing-feature`)
3. Commit your changes (`git commit -m 'Add some amazing feature'`)
4. Push to the branch (`git push origin feature/amazing-feature`)
5. Open a Pull Request

### Contribution Guidelines

- Follow the existing code style and conventions
- Write clear, descriptive commit messages
- Clearly explain the feature you have implemented in the pull request
- Ensure to properly test the feature and provide example seeds where the feature can clearly be seen working (if relevant)

For larger gameplay, ruleset, compatibility, or server-facing changes, make sure the expected multiplayer behavior is clearly explained and tested before opening a pull request.

### Looking to contribute but don't have a feature in mind?

Check the [original project issues](https://github.com/Balatro-Multiplayer/BalatroMultiplayer/issues) for upstream Balatro Multiplayer work and community discussion.
